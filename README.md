# 🎵 VK Desktop → Discord Status (Lyrics)

Автоматическое отображение текущего текста песни из **VK Desktop** в вашем **статусе Discord** (custom status).  
НЕ РАБОТАЕТ С БРАУЗЕРНОЙ ВЕРСИЕЙ!!!

---

## 📦 Требования

- **Windows 10 / 11**
- **Python 3.10 – 3.12** (подойдёт любая из этих версий)  
- **ВК Музыка (приложением)** я пользуюсь https://github.com/MaKrotos/Music-M
- **Discord** (десктопное приложение, открыто в фоне)

---

## 🚀 Установка и запуск (через start.bat)

1. **Скачайте репозиторий** или скопируйте файлы `main.py` и `start.bat` в одну папку.

2. **Установите Python** (если ещё нет):  
   - Скачайте с [python.org](https://python.org/downloads/)  
   - При установке **обязательно** отметьте галочку `Add Python to PATH`

3. **Установите VK Desktop** и войдите в свой аккаунт.

4. **Получите токен Discord** (один раз):  
   - Откройте Discord в **браузере** (не в приложении)  
   - Нажмите `F12` → вкладка **Network** → обновите страницу (`F5`)  
   - В фильтре введите `api` → выберите любой запрос к `discord.com/api`  
   - В **Request Headers** скопируйте значение `authorization` (длинная строка)  
   - Вставьте этот токен в файл `main.py` в строку `DISCORD_TOKEN = "СЮДА ТОКЕН"` В СКОБОЧКИ!!!

5. **Запустите `start.bat`** (двойным кликом).  
   - Батник сам проверит Python, установит нужные библиотеки и запустит скрипт.  
   - В консоли появится `Запуск — жду музыку из VK Desktop...`

6. **Включите любую песню в VK** – статус Discord начнёт обновляться строками текста!

---

## 🛠 Что делает start.bat

- Проверяет, установлен ли Python.
- Устанавливает необходимые пакеты: `aiohttp` и `winrt-Windows.Media.Control`.
- Запускает `main.py` с правильными правами.
